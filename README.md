# darren-email-assets

Public logos used in Darren's homelab, Job Hunt and Asana emails. Emails load them through jsDelivr:

`https://cdn.jsdelivr.net/gh/CtrlAltDarren/darren-email-assets@main/<path>`

- `logos/` – Darren's own report logos (e.g. `logos/darren-plex.png`)
- `companies/` – company logos saved by n8n for Job Hunt (`companies/<domain>.png`)

**Public on purpose. Logos only: nothing private, no data, no secrets.**
Service logos (Plex, Proxmox, TrueNAS…) come from homarr dashboard-icons instead.
